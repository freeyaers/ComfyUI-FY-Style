## Introduction

**FY Style** is a ComfyUI custom node plugin that provides a built-in style reference image gallery. Each reference image comes with ready-to-use simplified prompts.

- **1000+ style reference images**, curated from the open-source project [fal-Krea-2-Style-LoRA](https://huggingface.co/fal/krea-2-style-lora)
- **Flexible browsing and search**, supporting tag filtering and full-text search
- **Bilingual support (Chinese/English)**, language preference is automatically saved
- **One-click prompt injection** — the prompt of the selected image is automatically appended to your workflow

---

## Quick Start

1. Install the plugin into ComfyUI's `custom_nodes/` directory
2. Restart ComfyUI
3. Add the **FY Style** node to your workflow
4. Open the embedded gallery panel inside the node
5. Browse or search for the style you want, then click to select it
6. The node automatically outputs the selected image + corresponding prompt (optional), connect it directly to your image generation model

## File Description

| Path | Description |
|------|------|
| `__init__.py` | Plugin entry point |
| `nodes.py` | Core node implementation |
| `update.py` | HTML generator — parses filenames in `img/` directory, generates `index.html` gallery page |
| `js/main.js` | ComfyUI frontend extension — embeds gallery iframe, handles cross-frame message communication |
| `lang/` | Contains Chinese and English language packs (UI strings + category translations) |
| `img/` | Style reference image directory (naming convention: `[_tag]N-Name(prompt){URL}.ext`) |
| `img/fal-Krea-2-Style-LoRAs-Image.zip` | Image archive (automatically extracted on first node startup) |
| `workflows/` | Example ComfyUI workflows |
| `index.html` | Generated gallery page (auto-generated by `update.py`) |
| `update.bat` | Windows batch script, runs `update.py` to refresh the gallery |

## Image Naming Convention

You can customize style images by placing them in the `img/` directory. Please follow this naming format for style reference images:

```
[_tag]N-Chinese Name(English prompt ---- negative prompt){URL}.ext
```

| Part | Example | Description |
|------|------|------|
| `[_tag]` | `[_3d_rendering]` | Category tag (corresponds to the key in the language pack `classify`) |
| `N-` | `1-` | Sequence number |
| `Chinese Name` | `轻盈瓷蓝` | Chinese display name (shown in UI) |
| `(English prompt)` | `(airy porcelain blue style)` | Simplified positive prompt |
| `----` | `(Minimalist cyan line style ---- ambiguous, chaotic)` | Separator between positive and negative prompts |
| `{URL}` | `{https://hf-mirror.com/...}` | Source link (automatically decoded and displayed) |

After adding new images, run `update.py` ( or double-click the `.bat` file) to regenerate `index.html`.
